# Fixed Income Data Quality

Generic data-quality rules for fixed-income data. The rules are system-independent and describe business checks without prescribing an implementation.

Die Regeln decken vier Bereiche ab:

- **[Wertpapierstammdaten](rules/wertpapierstammdaten.md):** Instrumentenmerkmale, Klassifikationen, Kennungen und produktspezifische Anforderungen.
- **[Kupon und Cashflow](rules/kupon_cashflow.md):** Kupontermine, Zinsperioden, Zinstagekonventionen und kuponbezogene Angaben.
- **[Emittent und Kontrahent](rules/emittent_kontrahent.md):** Klassifikation, Zuordnung, Kennungen und systemübergreifende Konsistenz.
- **[Marktdaten](rules/marktdaten.md):** Kursverfügbarkeit, Instrumentenzuordnung, Einheiten und fehlende Werte.
